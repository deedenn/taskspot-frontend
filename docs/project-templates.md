# Шаблоны проектов

Открыть: /app/templates?type=projects. Вторая вкладка не заменяет существующие
шаблоны отдельных задач. Ссылка «Создать из шаблона» есть в окне нового проекта.

ProjectTemplates.jsx / ProjectTemplates.css реализуют библиотеку, просмотр состава,
создание проекта, сохранение структуры доступного администратору проекта,
удаление личных шаблонов, состояния загрузки, ошибки и повтор запроса.
Встроенные заготовки доступны и пользователю без собственных проектов.
Сохранение проекта как шаблона доступно только при наличии административной роли.
Права повторно проверяет backend, UI не является границей безопасности.

Название проекта и дата начала задаются перед созданием. В новый проект
переносятся открытые задачи и задачи в работе с категориями и чек-листами.
Ответственные, участники, файлы и комментарии не копируются.
Созданный проект открывается в параметрах: /app/projects/:projectId.

Для одинакового запроса после сетевой ошибки сохраняется UUID, предотвращающий
дублирование проекта. При изменении параметров создаётся новый UUID.
При отправке поля и закрытие модального окна блокируются.
Тарифные ошибки показываются в окне, рядом доступен переход в «Тарифы».

Проверки:
```sh
npm test
npm run lint
npm run build
node --test scripts/public-pages/public-pages.test.js
```

ProjectTemplates.test.jsx проверяет состав шаблона, повтор с прежним UUID,
переход в новый проект, выбор только административных проектов и повтор загрузки.

Сборка требует одновременного обновления backend с API project-templates.
Описание ограничений, API и требований MongoDB находится в backend/docs/project-templates.md.
Визуальный прогон desktop/mobile в браузере пока не выполнен из-за ограничений
запуска Chromium в окружении разработки.
