# Доработки по документу «Задачи для таскспот»

Дата: 7 сентября 2026.

## Реализация по пунктам

1. Выбор срока новой задачи: русская локаль Day.js, неделя начинается с понедельника.
2. Удаление категории: управляемое окно подтверждения, состояние отправки, сохранение ошибки и повтор. Backend атомарно удаляет категорию из проекта, его шаблонов задач и ссылок задач; остальные поля задач, включая updatedAt, не меняются.
3. Контроль → По ответственным: отдельная страница с аватарами, именем и фамилией, количеством задач по статусам, сроками и проектами. Фильтры по проекту и ответственному, постраничные списки людей и задач.
4. Календарь: неделя с понедельника.
5. Главная: удалены дублирующие показатели «показано / просрочено / скоро / срочно». Быстрые фильтры сохранены.
6. Главная: у зарегистрированного ответственного показаны аватар, имя и фамилия вместо email. У ожидающего регистрации остаётся email.
7. Таблица: семь колонок с относительными ширинами, переносами текста и фиксированной раскладкой, без принудительной ширины 1270px. На планшетах сайдбар сворачивается; до 768px используются мобильные строки.
8. Общий поиск в шапке: доступен со всех страниц обычного пользователя. Enter открывает отдельную страницу результатов; локальное поле поиска главной убрано. Поиск по тексту задачи, комментариям, чек-листу, названиям вложений, участникам, проекту и категориям. Содержимое бинарных файлов не индексируется.
9. Ответственный меняет статус в строке задачи: «В работе» или «Выполнено» → проверка. На мобильном выбор статуса не вложен в ссылку. Проверку и закрытие выполняет инициатор через карточку. Архивные проекты недоступны для изменений. Исправлено затирание обновлённой задачи старой копией в состоянии главной.
10. Вложения: область загрузки занимает доступную ширину; длинные имена переносятся, мобильные действия не перекрывают файл. Существующий механизм немедленной загрузки сохранён.
11. История задачи расположена после комментариев.
12. Кнопка «Отметить как выполненную» находится справа от заголовка; на телефоне под ним. Доступна только ответственному активной задачи.

## Проверка

- Backend: 92 теста, без пропусков, на отдельном локальном MongoDB replica set.
- Frontend: 38 тестов Vitest, включая реальный DatePicker/Calendar, удаление категорий с ошибкой и повтором, общий поиск, контроль, обновление статуса в таблице и мобильной строке.
- SEO: 10 тестов генератора публичных страниц.
- Production-сборка проходит; остаётся предупреждение о размере общего чанка Ant Design.
- Полный визуальный прогон Chromium заблокирован окружением macOS (MachPortRendezvousServer, Permission denied). Размеры и отсутствие наложений нужно дополнительно подтвердить в браузере.
- ESLint не запущен: в установленном node_modules отсутствует исполняемый файл eslint.

## Ручная приёмка

На ширинах 390, 768, 1024 и 1440px проверить главную, карточку задачи, поиск и контроль:
- все колонки таблицы, включая приоритет, видны без горизонтальной прокрутки;
- длинные ФИО, названия проектов, категорий и файлов не перекрывают действия;
- после «Выполнено» статус сразу становится «Проверка» и сохраняется после перезагрузки;
- чужой задаче и архивному проекту изменение статуса недоступно;
- поиск не показывает задачи за пределами прав пользователя;
- удалённая категория исчезает из проекта и задач, сами задачи остаются;
- загрузка и удаление вложения работают после повторного открытия задачи.

## Деплой

Изменения находятся непосредственно в frontend и backend. Коммитить и развёртывать оба репозитория: общий поиск и контроль используют новые endpoints /api/workspace/tasks и /api/workspace/assignees. Новые переменные окружения не требуются. Для атомарного удаления категорий MongoDB должен работать как replica set (MongoDB Atlas поддерживает транзакции). Продакшн-данные в ходе проверки не изменялись.
